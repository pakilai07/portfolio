# Portfolio design

Approved in chat: English editorial portfolio, warm off-white, dark typography, green CTA, restrained motion. Next.js App Router and Tailwind CSS. All sections responsive.

Order: introduction with Upwork CTA; experience carousel with blank image spaces; animated technology stack; case studies with problem, responsibility, solution, evidence and optional demo link; four-step How it works; email, Upwork and GitHub footer. Fixed reading progress starts at 0 and reaches 100 at the bottom.

No personal biography, employment, skills or results are verified. Draft content is explicitly identified. Upwork uses the platform homepage until a personal URL is supplied. Email is disabled until supplied. No invented results. Image areas intentionally blank as requested. No deployment requested.
